# Projekt "Umbrella"

Es gilt, eine einfache App zu erstellen, welche anzeigt, ob heute ein Schirm nötig ist oder nicht.

Mögliche Wetter-API: https://api.met.no/weatherapi/, Locationforecast 2.0.

Vorgaben, MUSS:

- Die Anwendung muss als PWA umgesetzt sein
- Der Name der App muss "<Name>s Umbrella" heissen. Beispiel: "Andrés Umbrella"
- Es müssen "About"-Informationen verfügbar sein 
  Die Implementierung ist frei: eigener Tab, kleine Fusszeile, Link oder auch Easter-Egg-Link, z. B. Double-Tap auf Bild
- Das Projekt muss im neuen Projekt Repo umgesetzt werden.
- Die App muss deployt werden, und ersetzt die zuvor bereitgestellte App (Fairhouse und Delights)

SOLL:

- Die App soll ansprechend aussehen
- Zugriffe auf die API sollten für eine gewisse Zeit gecacht werden, um API‑Aufrufe zu reduzieren 

KANN:

- Es kann zwischen verschiedenen Darstellungen gewählt werden
